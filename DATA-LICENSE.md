# Data sources and reuse

Any license applied to this repository's code does not grant rights to examination papers, answer keys, audio, images, or other files obtained from source organizations. Those files retain their original rights and source-specific terms. A public download is not, by itself, evidence of permission to republish or reuse it.

The maintained [source inventory](catalog/source-inventory.json) records each provider's official scope, source links, and reviewed publication concerns. [Provider notes](docs/providers/notes.md) add source-specific judgment where needed. These executable and generated records are the current source list; this page does not duplicate it.

Some official datasets are expressly released under Taiwan's [Open Government Data License, version 1.0](https://data.gov.tw/license). For material that a source identifies under that license, credit the providing organization, the dataset or work name and version or year, and the license. The license applies only to material that the providing organization has actually released under it; it does not automatically cover every linked examination file or third-party work.

If a file appears to have incorrect attribution, restricted rights, or a broken source link, please [open an issue](https://github.com/balaboom123/tw-exam/issues) or use the contact channel on the site. The project can review and remove an affected public bundle while preserving the source record needed to investigate it.
